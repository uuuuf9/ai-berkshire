## 核心思想

彼得·林奇的选股哲学可以概括为三句话：
1. **业余投资者有优势**——你在生活中接触到的产品和行业，比华尔街分析师更早发现好公司。
2. **先分类，再估值**——不同类型的公司，估值方法和持有逻辑完全不同。
3. **十倍股有迹可循**——大牛股往往有相似的特征（名字无聊、业务无聊、被人忽视、有护城河……），也有明确的红旗（多元恶化、高负债、单一客户依赖……）。

> 林奇名言："投资的乐趣在于，你可以在日常生活中发现伟大的公司，比华尔街早几个月甚至几年。"

## 第一步：公司分类——六种类型

任何一只股票，先归类再分析。不同类型的公司，预期收益、持有周期、估值方法完全不同。

| 类型 | 英文 | 核心特征 | 预期收益 | 关键指标 | 典型代表 |
|------|------|---------|---------|---------|---------|
| 缓慢增长型 | Slow Growers | 大公司、成熟行业、增速<10%、主要吃股息 | 年化5-10% | 股息率、派息率、股息增长连续性 | 公用事业、大型烟草 |
| 稳定增长型 | Stalwarts | 大公司、增速10-20%、穿越周期 | 年化10-15% | PE、盈利稳定性、护城河 | 可口可乐、宝洁 |
| 快速增长型 | Fast Growers | 小公司、增速20-50%、新业务/新市场 | 年化20%+（十倍股主力） | 营收增速、新店/新品扩张空间、ROE | 成长型新兴公司 |
| 周期型 | Cyclicals | 盈利随经济周期大幅波动 | 周期底部到顶部3-5倍 | 产能利用率、库存、供需缺口 | 钢铁、航空、汽车、化工 |
| 困境反转型 | Turnarounds | 经历重大危机、濒临破产、正在修复 | 反转成功2-10倍 | 债务结构、现金流、管理层变动、重组进展 | 危机后重生的公司 |
| 隐蔽资产型 | Asset Plays | 市场未发现的隐蔽资产（房产/土地/专利/子公司） | 资产重估2-5倍 | 资产净值vs市值、隐蔽资产明细、催化剂 | 持有大量不动产/股权的公司 |

**分类的动态性**：一家公司不会永远属于同一类型。快速增长型最终会变成稳定增长型，周期型在周期顶部看起来像快速增长型——识别错类型是最大的估值陷阱。

**分类判定流程**：
1. 看市值大小 + 行业成熟度 → 初步判断大/中/小盘
2. 看近3-5年收入/利润增速 → 判断增长快慢
3. 看盈利波动性 → 判断是否周期
4. 看是否处于困境/反转 → 排除法
5. 看资产负债表是否有隐藏价值 → 资产 play 判定

## 第二步：十三项特征——完美股票的画像

林奇在《彼得·林奇的成功投资》第9章总结了"完美股票的13个特征"。满足越多，成为十倍股的概率越高。

| # | 特征 | 为什么重要 | 检验方法 |
|---|------|-----------|---------|
| 1 | 名字听起来枯燥乏味甚至荒唐 | 名字越无聊，机构越不会主动研究，定价不充分 | 公司名是否"性感"？是否带"科技""生态""新经济"等热词？ |
| 2 | 业务枯燥乏味 | 无聊的生意没人竞争，容易形成垄断 | 主营业务描述是否让人"一听就不想研究"？ |
| 3 | 业务令人厌恶/不舒服 | 别人不想碰的领域，竞争最少 | 是否涉及垃圾、殡葬、厕所、害虫防治等"脏活累活"？ |
| 4 | 它是母公司分拆出来的 | 分拆出来的子公司有激励、有自主权、被市场忽视 | 是否是近期分拆上市？母公司持股比例？ |
| 5 | 机构不持股，分析师不跟踪 | 没有机构覆盖=没有被充分定价=alpha空间大 | 机构持股比例？跟踪分析师数量？是否被纳入主要指数？ |
| 6 | 有负面谣言缠身 | 谣言制造恐惧，恐惧制造低价 | 是否有"行业要完了""公司有重大问题"等悲观叙事？ |
| 7 | 行业让人沮丧/增长缓慢 | 零增长行业里，优秀公司可以不断蚕食份额 | 行业整体增速如何？龙头份额是否在持续提升？ |
| 8 | 它有利基/护城河 | 没有护城河的高增长会被竞争者迅速吞噬 | 是什么阻止竞争对手进入？品牌/专利/规模/网络效应/转换成本？ |
| 9 | 用户要不断购买/重复消费 | 重复消费=持续现金流=可预测的未来 | 客户复购率？是否是耗材/订阅/高频消费模式？ |
| 10 | 它是内部人买入的公司 | 内部人用真金白银投票，是最可信的信号 | 近6个月是否有董事/高管/大股东增持？增持价多少？ |
| 11 | 公司在回购股票 | 回购=管理层认为股价被低估+减少流通盘=EPS提升 | 近12个月回购金额/市值比例？回购价格区间？ |
| 12 | 小公司， niche market 龙头 | 小公司才有十倍空间，细分龙头有定价权 | 市值规模？细分市场份额？还有多少扩张空间？ |
| 13 | 低成本生产商 | 成本优势是最持久的护城河之一，尤其在同质化行业 | 单位成本 vs 竞争对手？毛利率行业排名？ |

**评分规则**：
- **★★★★★（5星）**：满足10项以上——高度符合十倍股画像
- **★★★★（4星）**：满足7-9项——有大牛股潜质
- **★★★（3星）**：满足4-6项——平庸，不突出也不差
- **★★（2星）**：满足2-3项——大概率不是十倍股
- **★（1星）**：满足0-1项——基本排除

## 第三步：红旗警告——这些股票要避开

林奇反复强调：避开陷阱和找到好股票同样重要。以下是明确的卖出/回避信号：

### 红旗一：多元恶化（Diworsification）

公司有钱了就乱收购、乱多元化，把好生意赚的钱糟蹋在坏生意里。
- 检测：过去3年是否有3次以上不相关的收购？
- 反例：专注主业的公司反而不断回购股票

### 红旗二：高负债

负债过高的公司，一旦遇到行业低谷就有生存危机。
- 检测：资产负债率 > 60%？净负债/EBITDA > 3倍？
- 例外：银行/保险等金融机构天然高杠杆，看资本充足率

### 红旗三：增长依赖单一客户

超过30%的收入来自单一客户，客户一换供应商公司就完了。
- 检测：前五大客户收入占比？最大客户占比？

### 红旗四：管理层频繁变动/不靠谱

林奇特别看重管理层是否诚实、是否把股东利益放在心上。
- 检测：过去3年换了几任CEO？管理层薪酬是否和业绩挂钩？是否有大股东掏空？

### 红旗五：盲目扩张到不相关领域

"我们要做XX界的苹果"——当一家公司开始说这种话的时候就是危险信号。
- 检测：公司战略是否在不断漂移？是否频繁更换"第二增长曲线"？

### 红旗六：市盈率远高于增长率

即使是好公司，买太贵了也不会赚钱。
- 检测：PEG > 1.5（林奇的安全边际线）

## 第四步：估值检验——PEG 是核心工具

林奇最著名的估值指标是 **PEG 比率**（市盈率相对盈利增长比率）。

**公式**：
```
PEG = PE / 盈利增长率（用%数字，不带百分号）
```

**林奇的 PEG 估值标尺**：

| PEG | 估值判断 |
|-----|---------|
| < 0.5 | 极度低估，可能是十倍股 |
| 0.5 - 1.0 | 低估，值得买入 |
| 1.0 | 合理，可持有 |
| 1.0 - 1.5 | 略贵，谨慎买入 |
| > 1.5 | 高估，回避 |

**注意事项**：
1. **增长率用什么**：优先用未来3-5年预期净利润复合增速，次选近3年历史增速。林奇偏好"可持续的增长率"而非一年暴增。
2. **PE 用什么**：用动态PE（当前市值/预期未来12个月净利润），不要用静态PE。
3. **不同类型公司的 PEG 适用度**：
   - 快速增长型：最适用
   - 稳定增长型：可用，但要加回股息率（PEGY = PE / (增长率 + 股息率)）
   - 周期型：不适用——周期顶部PE最低但最贵，周期底部PE最高但最便宜
   - 困境反转型：不适用——反转前没利润
   - 隐蔽资产型：不适用——看资产净值
4. **增长率必须可持续**：靠一次性收入的增长不算数。

**必须通过 financial_rigor.py 验证的估值数据**：
- 当前股价和总股本 → 市值验算
- 最新财年净利润 → 多源交叉验证
- 历史增速 → 手算复合增长率与第三方对比
- 动态PE → 用验证后的市值和净利润精确计算

调用方式：
```bash
python3 tools/financial_rigor.py verify-market-cap --price {股价} --shares {总股本} --reported {报告市值} --currency {币种}
python3 tools/financial_rigor.py cross-validate --field 净利润 --values '{"年报": x, "Yahoo": y, "东方财富": z}' --unit 亿
python3 tools/financial_rigor.py calc --expr '{市值} / {净利润}'
```

## 第五步：综合评级——林奇买入/卖出/持有判断

### 林奇式买入清单

同时满足以下条件，进入"林奇买入清单"：
1. [ ] 公司类型识别正确，且该类型有明确的投资逻辑
2. [ ] 13项特征满足7项以上（4星及以上）
3. [ ] 没有命中任何红旗（或红旗已被充分解释/正在改善）
4. [ ] 估值合理（快速增长型PEG < 1.0，稳定增长型PEGY < 1.0，其他类型有对应估值锚）
5. [ ] 你理解这家公司的生意——"我为什么要买它？"一句话说得清

### 林奇式卖出信号

出现以下任何一种情况，考虑卖出：
1. **故事讲完了**——快速增长型公司增速降到15%以下，变成稳定增长型
2. **估值太贵了**——PEG > 2.0，股价已经透支了未来3年的增长
3. **基本面恶化**——护城河在变弱，竞争加剧，管理层犯错
4. **有更好的选择**——发现了另一只更便宜、更优质的股票
5. **困境反转失败**——公司没有好转，反而更糟了

### 林奇式持有原则

- **不要因为涨了就卖**——十倍股涨50%的时候卖了，剩下的950%就和你没关系了
- **不要因为跌了就买**——下跌不代表便宜，可能是基本面恶化的信号
- **定期检查，不是天天盯盘**——每季度看一次财报，确认故事还在不在
- **分散但不过度分散**——林奇建议个人投资者持有5-10只股票，太少不够分散，太多跟踪不过来

## 注意事项

1. **林奇不是纯价值投资**——他买成长股、买周期股、买反转股、买资产股，核心是"知道你买的是什么类型，用对应的方法估值"。不要把PEG套用到所有类型上。
2. **生活中的优势**——林奇特别强调个人投资者可以从自己的职业和生活中发现投资机会。如果分析的是你熟悉的行业/公司，在报告中注明"生活验证"优势。
3. **不要迷信特征数量**——13项特征是画像不是教条。有些伟大公司只满足5-6项，但那几项特别强（比如极深的护城河+极高的内部人买入）。
4. **周期股的特殊难度**——周期股是林奇6种类型里最难把握的，需要对行业供需有深刻理解。没有把握时标注"周期判断置信度低"。
5. **反转股的高风险高收益**——困境反转型一旦成功收益巨大，但失败率也极高。林奇建议用小仓位分散参与。
6. **与现有技能的关系**：
   - 先用 `quality-screen`（去劣筛选）排除坏公司
   - 再用本技能做林奇式选股分析
   - 深度研究用 `investment-research`（四大师框架）
   - 财报验证用 `earnings-review`

## 局限性声明

彼得·林奇的方法产生于1970-1990年代的美股市场环境，当时机构投资者占比还没这么高，市场有效性也不如今天。在当前市场环境下：
- "机构不覆盖"的机会越来越少（但中小盘仍然存在）
- 十倍股的数量可能更少，需要更耐心
- 科技股的商业模式和传统行业不同，部分特征需要调整适用

林奇的方法的核心价值不在于13条特征的字面内容，而在于**逆向思维**——找别人忽视的、研究别人不研究的、在冷门行业里挖金子。

> "投资的窍门不是要你相信自己的内心，而是要你约束自己不去理会内心的恐惧和贪婪。你要做的就是比市场更有耐心，更理性，更愿意在别人恐慌的时候买入。"——彼得·林奇
