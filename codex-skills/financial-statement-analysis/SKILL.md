# 财报分析Skill - 基于《一本书读懂财报》

本Skill严格按照肖星教授《一本书读懂财报》的方法论，对上市公司进行系统性财务报表分析。

## 核心理念（来自《一本书读懂财报》）

企业只做三件事：**经营、投资、融资**。三张财务报表完整还原企业经营全貌。

- **资产负债表** = 企业的"单反相机"：时点数，展示企业的家底
- **利润表** = 企业的"摄像机"：时期数，展示企业如何盈利
- **现金流量表** = 企业的"验血报告"：展示现金的来龙去脉

---

## 执行流程

### 第一步：获取数据

1. **确认目标公司**：询问用户要分析的上市公司股票代码或名称
2. **获取近5年三大报表数据**：
   - 资产负债表（Balance Sheet）
   - 利润表（Income Statement）
   - 现金流量表（Cash Flow Statement）
3. **获取公司当前问题与未来计划**：通过搜索公司公告、年报、新闻了解：
   - 当前面临的主要问题/挑战
   - 管理层的未来战略规划
   - 行业环境与竞争格局

**数据获取方式推荐**：
- 使用Python的`akshare`、`tushare`、`baostock`等财经数据包
- 从东方财富、同花顺、雪球等财经网站爬取公开数据
- 参考公司官方年报、半年报、季报

### 第二步：三大报表拆解分析

#### 2.1 资产负债表分析

**资产部分**：
- 流动资产：货币资金、应收账款、存货、其他流动资产
- 非流动资产：固定资产、无形资产、长期投资、商誉等

**负债部分**：
- 流动负债：短期借款、应付账款、预收账款
- 非流动负债：长期借款、应付债券

**股东权益**：
- 实收资本、资本公积、盈余公积、未分配利润

**关键检查点**：
- 资产结构是否健康？重资产还是轻资产？
- 应收账款占比是否过高？是否存在坏账风险？
- 存货周转是否存在问题？
- 有多少负债需要偿还？短期偿债压力如何？
- 商誉是否过高？有无减值风险？

#### 2.2 利润表分析

**利润计算步骤**（来自书中Part13-17）：
1. 营业收入 - 营业成本 = 毛利
2. 毛利 - 营业税金及附加 - 营业费用 - 管理费用 - 财务费用 = 营业利润
3. 营业利润 + 营业外收入 - 营业外支出 = 利润总额
4. 利润总额 - 所得税 = 净利润

**关键检查点**：
- 营业收入增长趋势如何？
- 毛利率是否稳定/提升？
- 三项费用（销售、管理、财务）占比是否合理？
- 净利润是否来自主营业务？还是靠营业外收入？
- 是否存在成本失控问题？

#### 2.3 现金流量表分析

**现金流分类**：
- **经营活动现金流（CFO）**：企业造血能力
- **投资活动现金流（CFI）**：企业的投入/产出
- **筹资活动现金流（CFF）**：企业的输血/还钱

**健康现金流特征**（来自书中Part63-72）：
- ✅ 经营活动现金流为正：企业能自我造血
- ⚠️ 投资活动现金流为负：企业在扩张（需关注投什么）
- 关注现金流类型组合：
  - **+++**：妖精型（大概率有问题）
  - **++-**：老母鸡型（成熟稳定，分红）
  - **+-+**：疯牛型（快速扩张，需关注风险）
  - **+--**：奶牛型（经营好，还债+投资，优质）
  - **-++**：骗钱型（靠融资度日，警惕）
  - **-+-**：赌徒型（经营差，借钱投资，高风险）
  - **--+**：大出血型（经营投资都差，靠输血活着）
  - **---**：死亡型（随时倒闭）

### 第三步：三表勾稽关系验证

- 利润表的净利润 → 资产负债表的未分配利润
- 现金流量表的现金净变动 → 资产负债表的货币资金变动
- 关注利润与现金流是否匹配：有利润没现金流 = 纸面富贵

### 第四步：财务比率分析

#### 4.1 盈利能力分析（来自书中Part38）

| 指标 | 公式 | 判断标准 |
|------|------|----------|
| 毛利率 | (营业收入-营业成本)/营业收入 | 越高越好，行业对比 |
| 净利率 | 净利润/营业收入 | 越高越好 |
| ROE（净资产收益率）| 净利润/股东权益 | **核心指标**，>15%优秀，>20%卓越 |
| ROA（总资产收益率）| 净利润/总资产 | 反映资产使用效率 |
| 投资资本回报率（ROIC）| 税后净营业利润/投资资本 | 应>投资资本成本（WACC） |

**关键判断**：企业是否真的赚钱？经济利润 = ROIC - WACC > 0才是真赚钱。

#### 4.2 营运能力分析（来自书中Part39）

| 指标 | 公式 | 判断标准 |
|------|------|----------|
| 应收账款周转率 | 营业收入/应收账款平均余额 | 越高越好，周转快 |
| 应收账款周转天数 | 365/应收账款周转率 | 越短越好 |
| 存货周转率 | 营业成本/存货平均余额 | 越高越好 |
| 存货周转天数 | 365/存货周转率 | 越短越好 |
| 流动资产周转率 | 营业收入/流动资产平均余额 | 越高越好 |
| 固定资产周转率 | 营业收入/固定资产平均余额 | 越高越好 |
| 总资产周转率 | 营业收入/总资产平均余额 | 越高越好 |

**关键判断**：企业运营效率如何？资产周转快慢反映管理能力。

#### 4.3 偿债能力分析（来自书中Part40-41）

**短期偿债能力**：
| 指标 | 公式 | 判断标准 |
|------|------|----------|
| 流动比率 | 流动资产/流动负债 | >2较安全，但不是绝对 |
| 速动比率 | (流动资产-存货)/流动负债 | >1较安全 |
| 现金比率 | 货币资金/流动负债 | 最保守的指标 |

**长期偿债能力**：
| 指标 | 公式 | 判断标准 |
|------|------|----------|
| 资产负债率 | 总负债/总资产 | 40%-60%较合理，因行业而异 |
| 利息收入倍数 | 息税前利润/利息费用 | 越高越好，>3较安全 |

### 第五步：影响因素分析（来自书中Part42-49）

1. **行业大环境**：行业所处周期、竞争格局
2. **战略定位**：成本领先战略 vs 差异化战略
   - 成本领先：低毛利、高周转
   - 差异化：高毛利、低周转
3. **战略执行能力**：战略是否有效落地

### 第六步：好公司判断（来自书中Part50-56）

**好公司的标准**：
1. **赚钱**：ROIC > WACC，创造经济利润
2. **持续赚钱**：盈利能力指标连续多年稳定或提升
3. **赚钱效率高**：营运能力强，资产周转快
4. **财务健康**：偿债能力充足，现金流健康
5. **有成长性**：营业收入、净利润持续增长

**投资资本成本及格线**：通常用WACC（加权平均资本成本）衡量，一般企业在8%-12%左右。

**股东提高收益的方式**：
- 提高ROIC
- 适度使用财务杠杆（但要控制风险）

### 第七步：排雷避坑检查

⚠️ **危险信号清单**：
1. 经营活动现金流持续为负
2. 应收账款/存货异常增长，远超营收增速
3. 毛利率突然大幅下降
4. 资产负债率过高，短期偿债压力大
5. 商誉占净资产比例过高（>30%警惕）
6. 频繁更换会计师事务所
7. 大股东频繁质押股票
8. 净利润主要来自非经常性损益
9. 关联交易占比过高
10. 审计报告被出具非标意见

## 输出要求

最终输出一份完整的HTML格式分析报告，包含以下部分：

### 报告结构

1. **公司概况**
   - 公司基本信息
   - 主营业务
   - 当前面临的问题
   - 未来发展计划

2. **近5年财务数据概览**
   - 三大报表核心数据表格
   - 关键趋势图表（营收、净利润、现金流趋势）

3. **三大报表详细解读**
   - 资产负债表分析
   - 利润表分析
   - 现金流量表分析（含现金流类型判断）

4. **财务能力分析**
   - 盈利能力分析（含ROE、ROIC、毛利率、净利率）
   - 营运能力分析（各项周转率）
   - 偿债能力分析（短期+长期）

5. **三表勾稽与现金流质量**
   - 利润与现金流匹配度
   - 现金流健康度评估

6. **行业与战略分析**
   - 行业对比
   - 公司战略定位与执行效果

7. **风险提示**
   - 排雷检查结果
   - 主要风险点

8. **投资结论**
   - 是否是好公司？（给出明确判断：优质/良好/一般/较差）
   - 是否值得投资？（给出建议：强烈推荐/推荐/观望/回避）
   - 核心逻辑支撑

## 注意事项

1. **数据真实性**：优先使用官方年报数据，交叉验证多个数据源
2. **行业差异**：不同行业财务指标标准不同，必须进行行业对比
3. **历史趋势**：不能只看单一年份，要看5年趋势变化
4. **眼见不一定为实**：财务数据可能被粉饰，要结合多维度判断
5. **现金流为王**：利润是纸面的，现金流是真实的
6. **免责声明**：分析仅供学习参考，不构成投资建议
