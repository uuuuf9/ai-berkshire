# 行业分析 Skill

基于麦肯锡前分析师肖璟《如何快速了解一个行业》的系统方法论，帮助你在1-2周内快速建立对陌生行业的深度认知。

## 适用场景

当遇到以下情况时，请调用此skill：
- 用户需要了解某个陌生行业的全貌
- 需要撰写行业研究报告或分析文章
- 投资决策前的行业尽调
- 求职/跳槽前对目标行业的调研
- 创业前的赛道选择与机会评估
- 需要分析产业链上下游关系、定价权、增长预测等特定维度

---

## 第一部分：行研框架篇（核心分析框架）

### 1.1 产业生命周期定位

首先判断行业所处的生命周期阶段，不同阶段研究重点不同：

| 生命周期阶段 | 核心研究重点 | 关键问题 |
|------------|------------|---------|
| **导入期** | 商业模式可行性 | 需求是否真实？盈利能否持续？能否大规模复制？ |
| **成长期** | 市场规模与增速 | TAM有多大？未来3-5年SAM增速？渗透率提升空间？ |
| **成熟期** | 护城河与竞争格局 | 行业护城河够宽吗？市场集中度如何？利润如何分配？ |
| **周期波动期** | 供需与产能周期 | 供给是否受限？产能周期如何变动？ |
| **衰退期** | 替代品风险 | 有没有颠覆性替代品？是自然衰老还是替代式衰退？ |

**重要提醒**：各阶段分析不是互斥的，只是权重不同。即使导入期也要考虑后续规模性和防守性。

### 1.2 五维分析框架

任何行业都要系统覆盖以下五个维度：

#### 维度一：行业概况
- 市场规模（TAM/SAM/SOM三口径）
- 历史增速与未来3年增长预测
- 所处产业生命周期阶段
- 核心驱动因素（技术/政策/需求/供给）

#### 维度二：产业链与价值链
- 完整产业链图谱（上游-中游-下游）
- 各环节市场规模与增速
- **利润池分布**：哪个环节最赚钱？为什么？
- 上下游议价能力分析
- 关键成功要素在哪个环节

#### 维度三：定价权分析
- 行业整体定价能力：是价格接受者还是制定者？
- 产业链各环节定价权对比
- 定价权来源分析（品牌/技术/资源/网络效应/规模）
- 价格传导机制：成本上涨能否顺利向下游传导？
- 历史价格走势与未来价格趋势判断

#### 维度四：竞争格局
- 市场集中度（CR3/CR5/CR10）
- 头部企业市场份额与变化趋势
- 波特五力分析：
  - 现有竞争者竞争强度
  - 潜在进入者威胁
  - 替代品威胁
  - 供应商议价能力
  - 购买者议价能力
- 护城河分析：资源垄断 vs 网络效应

#### 维度五：风险与趋势
- 政策风险与监管导向
- 技术迭代风险
- 宏观经济影响
- 未来3年核心趋势判断
- 潜在"行业杀手"识别

## 第二部分：研究方法篇（执行流程）

### 2.1 三步法研究流程

#### 第一步：快速建立认知框架（1-2天）

**目标**：从0到1建立行业基本认知，搞懂行业术语和基本逻辑。

**信息收集渠道**：
1. **入门资料**：
   - 行业百科词条（百度百科、维基百科）
   - 券商行业研究报告（慧博投研资讯、发现报告）
   - 咨询公司报告（麦肯锡、贝恩、BCG、艾瑞、易观）
   - 行业协会官网发布的白皮书/蓝皮书
   
2. **快速扫读头部公司**：
   - 找出行业内3-5家代表性上市公司
   - 阅读最近1-2份年报的"经营情况讨论与分析"章节
   - 浏览公司官网的业务介绍
   
3. **回答四个核心问题**：
   - 这个行业解决什么需求？（用户痛点是什么？）
   - 行业如何创造价值？钱从哪里来？（盈利模式）
   - 关键参与者有哪些？（供应商、渠道、客户、竞品）
   - 这个行业的"游戏规则"是什么？

**输出物**：
- 一页纸行业概览
- 关键术语清单
- 初步产业链草图
- 待验证的假设清单

#### 第二步：深入分析关键问题（3-5天）

**目标**：针对核心问题深度挖掘，交叉验证信息，建立完整分析框架。

**重点研究内容**：

**A. 产业链与上下游分析（必做）**
1. 绘制完整产业链图谱：
   - 上游：原材料、核心零部件、设备供应商
   - 中游：生产制造、组装、服务提供
   - 下游：渠道、终端用户、应用场景
   
2. 各环节深度分析：
   - 每个环节的市场规模与增速
   - 每个环节的竞争格局（集中度）
   - 每个环节的平均毛利率/净利率
   - 每个环节的龙头企业是谁
   - 利润在产业链中如何分配？利润池在哪里？
   
3. 上下游关系分析：
   - 上游集中度 vs 下游集中度（决定议价权）
   - 是否存在纵向一体化趋势？
   - 核心瓶颈环节在哪里？
   - 有没有卡脖子的环节？

**B. 定价权专项分析（必做）**
1. 定价权分层判断：
   - **强定价权**：能提价且销量不跌（如奢侈品、高端白酒、独家药品）
   - **中等定价权**：成本上涨能传导，但不能主动提价
   - **弱定价权**：价格接受者，只能随行就市（如大宗商品、普通代工）
   
2. 定价权来源识别：
   - **品牌溢价**：消费者愿意为品牌多付钱
   - **技术专利**：独家技术或专利保护
   - **资源垄断**：独占稀缺资源（矿产、牌照、渠道）
   - **网络效应**：用户越多价值越大（互联网平台）
   - **规模优势**：成本领先，能打价格战拖垮对手
   - **转换成本**：用户切换成本高（如企业软件、银行）
   
3. 价格传导机制分析：
   - 上游原材料涨价时，企业能否提价转移成本？
   - 提价后销量/市场份额是否受影响？
   - 历史上几次成本周期中的表现如何？

**C. 未来3年增长速度预测（必做）**
1. 增速预测方法论：
   - **历史外推法**：参考过去3-5年CAGR，结合未来因素调整
   - **渗透率类比法**：对比成熟市场渗透率，测算提升空间
   - **政策目标法**：参考国家/行业规划中的明确目标
   - **下游需求拉动法**：测算下游行业增长对本行业的拉动
   - **专家意见法**：综合上市公司指引、券商一致预期、业内专家判断
   
2. 增长驱动因素拆解：
   - 量的增长：用户数/销量增长多少？
   - 价的增长：单价/ASP提升多少？
   - 结构变化：高端化/产品结构升级贡献多少？
   - 新业务/新市场：第二增长曲线贡献多少？
   
3. 情景分析：
   - 乐观情景：驱动因素超预期
   - 中性情景：基准假设
   - 悲观情景：风险因素爆发
   
4. 输出：未来3年逐年增速预测区间+CAGR

**D. 护城河与竞争分析**
1. 护城河四要素验证：
   - 无形资产（品牌、专利、牌照）
   - 成本优势（规模、流程、地理位置）
   - 网络效应（用户越多越有价值）
   - 转换成本（用户切换代价高）
   
2. 护城河变化趋势：
   - 护城河在加宽还是变窄？
   - 有没有潜在的破坏性创新？

**E. 商业模式分析**
使用商业模式画布九要素：
1. 客户细分
2. 价值主张
3. 渠道通路
4. 客户关系
5. 收入来源
6. 核心资源
7. 关键业务
8. 重要合作
9. 成本结构

**信息验证方法**：
- 对比多家券商报告的一致预期与分歧点
- 交叉验证财务数据与行业数据
- 寻找从业者观点（知乎、脉脉、行业社群、专家访谈）
- 用反常识思维：有没有什么信息不符合逻辑？

**输出物**：
- 完整产业链图谱（标注利润池）
- 定价权分析矩阵
- 未来3年增速预测表（三种情景）
- 竞争格局图谱
- 核心发现与关键假设清单

#### 第三步：验证与输出结论（1-2天）

**目标**：交叉验证信息，形成逻辑闭环的结论，结构化输出。

1. **交叉验证**：
   - 不同来源信息是否一致？矛盾点在哪里？
   - 关键假设是否成立？有没有反证？
   - 请1-2位业内人士帮忙审阅核心结论
   
2. **结构化输出**（金字塔原理）：
   - **核心观点**（1句话总结行业判断）
   - **分论点1：行业基本盘**（生命周期、规模、增速）
   - **分论点2：产业链与定价权**（利润池、议价能力）
   - **分论点3：竞争格局**（集中度、护城河）
   - **分论点4：未来趋势与风险**（3年展望、关键风险）
   - 每个分论点配数据/案例支撑

3. **最终交付物建议**：
   - 1页执行摘要（给没时间看全文的人）
   - 10-20页完整分析报告
   - 产业链图谱一张图
   - 核心数据表

### 2.3 信息源优先级

1. **最高可信度**：
   - 上市公司招股书、年报、公告、投资者关系活动记录
   - 行业协会官方统计数据
   - 政府部门公开数据（统计局、工信部、发改委等）
   
2. **较高可信度**：
   - 头部券商深度研报（30页以上）
   - 知名咨询公司报告（麦肯锡、贝恩、BCG等）
   - 行业资深专家公开发表的观点
   
3. **中等可信度**：
   - 行业媒体深度报道
   - 知乎/雪球等平台高质量长文
   - 上市公司业绩说明会纪要
   
4. **低可信度（需交叉验证）**：
   - 自媒体文章
   - 论坛传闻
   - 短平快的新闻报道

## 第三部分：研究进阶（高阶技能与避坑指南）

### 3.1 关键洞察技巧

1. **80/20法则**：不要陷入信息海洋，抓住影响行业的20%关键因素。
   - 例：对于消费品，渠道和品牌往往比技术更重要
   - 例：对于资源品，成本曲线和供需缺口比什么都重要

2. **关注不变的东西**：
   - 技术会变，但用户的本质需求很少变
   - 人性不变，经济规律不变
   - 问：这个行业10年后会是什么样？什么东西不会变？

3. **对比思考**：
   - 对比国内外同行业发展路径
   - 对比上下游的议价能力
   - 对比历史上相似阶段的行业表现

4. **寻找反共识机会**：
   - 一致预期往往已经反映在价格里
   - 当所有人都看好时要保持警惕
   - 找到市场预期差在哪里

### 3.2 常见陷阱与避坑指南

1. **避免线性外推**：
   - 高速增长不可能永远持续，成长期会转入成熟期
   - 警惕"这次不一样"的论调，历史往往押韵
   
2. **警惕幸存者偏差**：
   - 不要只看成功的企业，也要看失败的案例
   - 问：这个行业淘汰率有多高？失败者为什么失败？
   
3. **不要把相关性当因果性**：
   - A和B同时发生不代表A导致B
   - 多问一句：背后的真正原因是什么？
   
4. **避免锚定效应**：
   - 不要被第一份看到的报告锚定观点
   - 先建立自己的框架，再去看别人的观点
   
5. **产业链分析常见坑**：
   - 不要只看名义毛利率，要结合资产周转率、资本开支
   - 高毛利环节如果进入门槛低，很快会被竞争拉低
   - 注意"微笑曲线"是否在变形，利润池可能转移

6. **定价权分析常见坑**：
   - 短期提价成功不等于有定价权，要看可持续性
   - 要区分是产品结构升级带来的ASP提升，还是真的能提价
   - 强定价权行业往往有政策或品牌的深厚壁垒，不要轻易判断

7. **增速预测常见坑**：
   - 不要简单用过去增速线性外推未来
   - 渗透率到一定水平（如30%）后增速往往会下台阶
   - 注意基数效应，高基数下高增速难维持

### 3.3 AI时代的研究提效

1. **AI辅助初筛**：
   - 让AI帮你快速整理行业基本概念、术语解释
   - 让AI帮你总结多份研报的核心观点（但一定要自己验证）
   - 让AI帮你搭建初步的分析框架
   
2. **AI不能替代的部分**：
   - 对商业逻辑的深度理解
   - 对真伪需求的判断
   - 对人性和博弈的洞察
   - 最终的投资/商业决策
   
3. **高效人机协作流程**：
   - 第一步：AI帮你快速建立初步认知（节省1-2天）
   - 第二步：你深度思考核心问题，AI帮你找数据、做对比
   - 第三步：你形成结论，AI帮你结构化输出、做图表
